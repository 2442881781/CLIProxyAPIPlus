# Basispoints protocol source attribution

The files in this directory are adapted from `hloolx/codex2api` commit
`f52a47f2bd49208bd28ae1010049d7393fc01552`, whose README declares the MIT
License. Original Basispoints implementation by hloolx.

Source: https://github.com/hloolx/codex2api

CLIProxyAPI supplies its own credential lifecycle, routing, transport, logging,
usage accounting, configuration, and management API integration. This directory
contains only the protocol adapter used to translate Responses requests and
Basispoints SSE responses.
