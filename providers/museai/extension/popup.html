For the Muse.ai personal agent, not Meta Muse Code. Sign in to https://muse.ai in this Chrome profile first.

HTTPS is required, except HTTP on localhost or 127.0.0.1. Enter the origin only, including its port if needed; no path, query, or credentials. The request is sent to exactly this origin. Chrome host permissions apply to all ports on the selected host.

Click Import to request access to the selected CPA host and send all Muse.ai cookies, including HttpOnly cookies and actual persistent-cookie expiry times. Cookie values and your key are never displayed or stored by this extension. Session cookies have no fabricated expiry.

No network requests or cookie reads occur until you click Import.

Keep this popup open until completion. After a network failure, check the manager before retrying: the server may already have saved the account. Import does not probe Muse.ai or start a generation.
